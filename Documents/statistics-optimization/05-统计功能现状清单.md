## 1. 模块总览与数据流

```
播放行为发生
   └─> CPlayStatistics（单例采集器）            MusicPlayer2/PlayStatistics.h/.cpp
         └─> 按月落盘 JSONL：playlog_YYYY-MM.jsonl
   └─> WM_STAT_RECORD_APPENDED 通知 → 统计对话框实时刷新

用户打开「播放统计」（主界面菜单，ID_PLAY_STATISTICS = 33513）
   └─> CPlayStatisticsDlg（模态）               MusicPlayer2/CPlayStatisticsDlg.h/.cpp
         ├─ LoadRecords()   全量解析日志 → m_all_records（打开期只解析一次）
         ├─ ApplyFilter()   唯一时间过滤点 → m_filtered_records
         ├─ BroadcastContext() 广播 StatContext* 给 6 个子页
         ├─ 6 个页签（CTabDlg 子类，惰性刷新）
         └─ 按钮行：导出CSV / 导出JSON / 导出聚合CSV / 生成网页报告 / 关闭
```

**口径铁律**：所有聚合只统计「有效播放」，唯一判定收口在
`CStatAnalysis::IsCounted()`（`play_duration_sec >= 15`）。除明细页外全部聚合走它；
**明细页例外**（展示全部原始记录，用于核查，注释明确说明）。

## 2. 数据层

### 2.1 PlayRecord 字段（JSONL 每行一条）
| 字段 | 类型 | 含义 |
|---|---|---|
| file_path | string | 文件完整路径（主键） |
| title / artist / album | string | 标签信息（TagLib 读取） |
| genre | string | 流派标签（**界面已全部移除，仅日志仍记录**） |
| played_at | string | ISO 时间 `YYYY-MM-DDTHH:MM:SS` |
| play_duration_sec | int | 本次实际播放秒数（**口径字段**） |
| song_length_sec | int | 歌曲总长（毫秒×1000，注意单位是毫秒） |
| finish_reason | int | 0=COMPLETED 1=SKIPPED 2=STOPPED 3=PLAY_ERROR |
| volume / was_shuffled | — | 音量 / 随机标记 |
| playlist_source | string | 来源（"文件夹模式"/歌单名等） |
| bitrate / sample_rate / channels | int | 音频参数 |

### 2.2 采集与落盘（PlayStatistics.cpp）
- 单例 `CPlayStatistics::GetInstance()`；`Init(config_dir)` → 日志目录 = `config_dir + "statistics\\"`。
  实际位置：`%APPDATA%\MusicPlayer2[ (Debug)]\statistics\`（Debug 变体目录名带 " (Debug)" 后缀）。
- 文件名 `playlog_%04d-%02d.jsonl`，按月一个文件；`schema_changelog.txt` 记录版本变更，当前 `schema_version = 2`。
- `SetNotifyTarget(hwnd)`：追加记录后向统计对话框发 `WM_STAT_RECORD_APPENDED`（近实时刷新）+ 对话框内 60s 兜底定时器。
- 注意：`song_length_sec` 单位是毫秒，展示/聚合时需 `/1000`。

## 3. 聚合层（StatAnalysis.h/.cpp —— 纯函数，无 UI 依赖）

| 函数 | 输入 | 输出 | 用途 |
|---|---|---|---|
| `ComputeSummary(records)` | 全部记录 | `StatSummary`（见下） | 概览页/洞察页/报告共用的总指标 |
| `ComputeBuckets(records, grain)` | 记录+粒度(天) | `[{label,count,duration_sec}]` | 播放趋势（报告 02 节） |
| `ComputeHeatmapGrid(records)` | 记录 | `[{ymd,count,duration_sec}]` | 每日热力图 |
| `ComputeHourHistogram(records, int[24])` | 记录 | 24 桶次数 | 24 小时时段分布 |
| `ComputeSkipDistribution(records)` | 记录 | `[{index 0-3,label,count,percent}]` | 跳过位置分布（0-25/25-50/50-75/75-99%） |
| `ComputePlaylistContribution(records)` | 记录 | `[{source,count,duration_sec,percent}]`（前 5） | 歌单/来源贡献 |
| `ComputeYearlyReviews(records)` | 记录 | `[{year,count,duration_sec,top_artist,top_song}]` | 按年归档回顾 |
| `ComputeRetiredGems(records, 3)` | 记录 | `[{file_path,title,artist,count}]` | 遗珠挖掘：反复听 ≥3 次却从未完播（REQ-113） |
| `ComputeNewSongTrend(records)` | 记录 | `[{label,count}]` | 新发现歌曲趋势（仅网页报告用） |
| `ComputePeriodComparison(records, filter)` | 记录+过滤器 | `PeriodComparison`（环比/同比桶与差值） | 环比/同比（报告 02 节） |
| `ComputeRadar(summary)` | 汇总 | `{explore,focus,night,loyalty,fresh}` 0-100 | 五维听歌画像 |
| 工具 | — | `YmdOf / HourOf / YmdAddDays / FirstDayOfMonth / FormatDuration / IsCounted` | 时间解析与口径 |

**StatSummary 主要字段**：total_count / total_duration_sec / active_days / completed_rate / skip_rate /
avg_completion / current_streak / longest_streak / night_owl_percent / weekend_percent / new_songs_month /
repeat_depth / explore_percent / avg_plays_per_day / inflation_percent / top_artist(+sec) / top_song(+artist,+count) /
badges（徽章列表，含连续天数、探索型等，在 ComputeSummary 内生成）。

**已删除（2026-09-18 按用户决定）**：流派全家桶 —— `GenreShare` 结构、`ComputeGenreShare`、
`ComputeGenreShareByQuarter`、`ComputeCosineSimilarity`、`StatSummary.top_genre/top_genre_count`、
流派徽章、`StatAiInsight::GenreFamily/BuildDriftNarrative`。原因：用户曲库流派标签填充率仅 0.8%（实测）。

## 5. UI 层

### 5.1 主对话框 CPlayStatisticsDlg（IDD_PLAY_STATISTICS_DIALOG）
| 区域 | 控件 | 行为 |
|---|---|---|
| 过滤条 | `IDC_STAT_RANGE_PRESET` 下拉 | 近7天/近30天/近90天/今年/去年/全部/自定义；**默认全部**；顺序与 `RangePreset` 枚举一一对应 |
| | `IDC_STAT_DATE_FROM/TO`（SysDateTimePick32） | 「全部」时禁用并显示数据实际 min/max 日期；其它预设显示对应区间；用户改动 → 校验 from≤to（非法弹一次警告回滚）→ `preset=Custom` → 重新过滤广播 |
| 页签 | `IDC_STAT_TAB`（CTabCtrlEx） | 6 页：概览/歌手/专辑/曲目/明细/洞察；`SetCurTab` 切换 + 页面 `OnTabEntered` 惰性刷新 |
| 按钮行 | 4+1 | 导出CSV / 导出JSON / 导出聚合CSV / 生成报告 / 关闭 |

- **时间过滤唯一收口**：`ApplyFilter()`（`from_ymd/to_ymd`，0 = 无界）。子页禁止二次按日期过滤。
- `SetMinSize(DPI(600), DPI(360))`；`IsRememberDialogSizeEnable()=true`（记住上次尺寸，`.rc` 默认值仅首次生效）。
- 60s 定时器 + `WM_STAT_RECORD_APPENDED` 触发 `RefreshAllViews()`。

### 5.2 六个子页（均 `CStatTabDlg` 派生）
| 页签 | 文件 | 内容与数据来源 |
|---|---|---|
| 概览 | StatOverviewTabDlg | 两列列表（统计项/数值），分组「基本统计/播放结果」等；另持有小时直方、跳过分布、来源贡献、连续差一天数据（BuildData 已算，展示按需） |
| 歌手/专辑/曲目 | StatArtistRank/AlbumRank/SongRankTabDlg | 三列排行（#/名称/时长或次数），按累计时长(次数)降序 |
| 明细 | StatSongsTabDlg | 8 列（序号/播放时间/标题/艺术家/专辑/播放时长/歌曲长度/结果），**展示全部原始记录、不做 15 秒过滤**（核查用）；「来源」列已删 |
| 洞察 | StatProfileTabDlg | 只读多行编辑框，文本 = 音乐DNA + 听歌档案徽章 + AI洞察 + **遗珠挖掘**（从流派页迁入）+ 按年归档回顾 + 深度数字 |

### 5.3 交互要点
- 页签切换：`CTabCtrlEx::SetCurTab` → 页面 `OnTabEntered`（脏则 Refresh）→ 焦点交本页主控件（`GetFocusTarget`，滚轮由控件原生处理）。
- 列宽：各页 `OnInitDialog` 里按 `GetWindowRect` **实宽一次算定**（窄列固定 + 主内容列吃剩余，照 CListenTimeStatisticsDlg 范式），不随缩放重算。
- 子页内容超出可视区：走 `CTabDlg::SetScrollbarInfo`（父窗口 OnSize 重调，OptionsDlg 原生机制）。

## 9. 重构注意事项（项目原生约束，违反会翻车）

1. **样板**：主对话框照 `CListenTimeStatisticsDlg`；页签容器+子页照 `COptionsDlg`
   （`OptionsDlg.cpp:70-117` 创建/记设计高/`SetScrollbarInfo`，`:157-168` OnSize 重调）。
2. `.rc` 是 **UTF-16LE+BOM+CRLF**；`AFX_DIALOG_LAYOUT` 与控件**声明顺序**一一对应、成对出现。
3. 原生日历控件需 `ICC_DATE_CLASSES`（`MusicPlayer2.cpp:266` 已含）。
4. 列宽在 `OnInitDialog` 用 `GetWindowRect` 实宽一次算定（窄列固定+主列吃剩余）——项目既有范式。
5. 15 秒口径唯一收口 `IsCounted()`；明细页有意豁免（核查用）。
6. `song_length_sec` 是毫秒；`IsCounted` 用的 `play_duration_sec` 是秒。
7. 窗口尺寸：`.rc` 写死 + 记住上次大小
8. 洞察页只读编辑框不响应滚轮——如需滚轮需焦点在该控件或转发（重写时建议直接让编辑框获得焦点）。
